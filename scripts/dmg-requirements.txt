# and the two small libraries it is built on. Nothing else, and no compiled code.
#

# checksum is not listed here, so the code that builds the installer is the code that was
# read, whatever is published under the same name later.

#
#   printf 'dmgbuild==1.6.7\nds-store==1.3.3\nmac-alias==2.2.3\n' \
#       | uv pip compile --generate-hashes --python-version 3.12 --no-header -
#
